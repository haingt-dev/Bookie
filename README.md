# Bookie — Community Knowledge Hub

**Book!e Inspires Everyone** is a Vietnamese reading community running for 9+ years. This repo is the organization's public knowledge base plus a workspace for its sub-projects. Website: [bookiecommunity.com](https://bookiecommunity.com) · Fanpage: [facebook.com/bookie.community](https://facebook.com/bookie.community).

## Knowledge Base

[`knowledge/`](knowledge/README.md) is the centerpiece: institutional memory extracted from the organization's Google Drive (2016→2025) — history timeline, org structure, playbooks per program (Book!e Discussion, Book!e Talk, Gala, Meetup, CTV, MarCom…), yearly plans, meeting-minute knowledge, and a full Drive inventory. Content is in Vietnamese and PII-scrubbed for public hosting — see [`knowledge/_meta/PII-POLICY.md`](knowledge/_meta/PII-POLICY.md).
